# My Notes (web app)

The phone and iPad version of **My Notes**, hosted with GitHub Pages:
**https://rathikeshav92-afk.github.io/my-notes/**

On iPad or iPhone, open the link in Safari and tap **Share → Add to Home Screen**.

This repository holds only the built app. Notes are never stored here: each device keeps its notes
locally and syncs them with a private repository using a token you enter in the app's settings.
The source code lives in the private `Notes-app` repository (`app/`); this folder is a copy of `app/www/`.
